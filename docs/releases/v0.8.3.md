# Tg 0.8.3

## Display

- Merged top panel and stats into a single unified 192px drawing area
- Stats are column-aligned under their respective instantaneous labels (Accuracy, Beat Error, Amplitude) with mean/min/max/std dev stacked below each header
- Removed "Window 60s" / "Live window" / "Loaded snapshot" label from display and clipboard copy
- Instantaneous values now anchored to the top of the drawing area

## Interactions

- "Take Snapshot" button now immediately switches to the newly created snapshot tab
- Saving a snapshot as image renames the snapshot tab to the saved filename
- "Copy Stats" button updated to reference the unified output drawing area

## Fixes

- Fixed instant-values vertical centering after panel height change
- Stats columns now auto-align to the x-positions of their corresponding instant labels instead of hardcoded offsets

## Notes

- The output panel height is 192 px (was 70 px), now containing both the instantaneous line and windowed stats
- Calibrate mode is unchanged — stats are only rendered in live capture mode
- Renamed orientation labels now appear in the save-as-image confirmation dialog
