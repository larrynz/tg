# Tg 0.8.2

Feature and packaging release adding UI polish (Clear button, PNG export, color fixes) and comprehensive CI/CD pipeline fixes for Linux (DEB), Windows (MSI/WiX), and macOS.

## Features

### UI Improvements
- **Clear button** — Added next to "Copy Stats" in toolbar; clears all trace data (events, amplitudes, timestamps) and resets paperstrip zoom
- **Right-click Save As PNG** — Right-click any panel (top info, stats, paperstrip, tic/toc/period waveforms) to save as PNG with orientation prefix:
  - Dial Up, Dial Down, 12PM Down, 3PM Down, 6PM Down, 9PM Down
  - Filename format: `Orientation_YYYYMMDD_HHMMSS.png`
- **Signal quality color gradient reversed** — Now Red (coarse/stage 0) → Yellow → Green (fine/stage 2+) for intuitive visual progression (was previously green→yellow→red)

## CI/CD & Packaging Fixes

### GitHub Actions Workflow (New)
- Complete Linux / Windows / macOS build matrix
- Linux: builds AppImage and DEB packages
- Windows: builds MSI installer via WiX toolset
- macOS: builds universal binary with Homebrew dependencies
- Artifact upload with proper retention
- Container-based Linux builds for reproducibility
- `HOMEBREW_NO_REQUIRE_TAP_TRUST` for macOS runner compatibility

### DEB Packaging
- Fixed artifact collection with debug `find` command to reliably locate generated `.deb` files

### Windows MSI / WiX Fixes
- Fixed WiX `candle` `-d` flag syntax
- Fixed WiX `heat`: use `-var var.ResourcesDir` for correct paths
- Fixed WiX: copy `tg-timer.wxs` to MSI directory before build
- Fixed Debian changelog version and WiX install steps
- Fixed MSI pipeline without PHP dependency

### Workflow Hardening
- Removed `artifact retention-days` that caused issues
- Fixed YAML syntax errors in workflow
- General workflow stability improvements
